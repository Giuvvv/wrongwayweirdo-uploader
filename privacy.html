Privacy Policy — wrongwayweirdo uploader

Last updated: 3 November 2026

1. Summary

wrongwayweirdo uploader is a private tool used only by the owner of the @wrongwayweirdo channel to upload the owner's own videos to the owner's own TikTok account. It does not collect data about anyone else.

2. Data the tool uses

  • The TikTok access token and account identifier (open ID) that TikTok returns when the owner signs in and approves the tool.
  • Basic profile information of the owner's account (display name), used only to confirm the right account is connected.
  • The video files and captions the owner chooses to upload.

3. Where it is stored

The token is stored only in a local file on the owner's computer. It is not sent to any server other than TikTok's own API. Nothing is sold, shared or used for advertising.

4. Other people's data

The tool does not read, collect or store information about other TikTok users, viewers or followers.

5. Retention and deletion

The owner can delete the local token file at any time and can revoke the tool's access from the TikTok app settings (Security and permissions → Apps and services).
